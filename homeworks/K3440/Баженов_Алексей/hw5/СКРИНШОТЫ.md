## Рисунок 5 – Notes app с добавленными заметками

⚠️ **Важно:** для этого скрина нужно запустить **json-server** с моковым API!

**Что сделать:**

1. Создай файл `vue-project/db.json`:
```json
{
  "notes": [
    {
      "id": 1,
      "name": "1 заметка",
      "text": "Это текст первой заметки",
      "userId": 1
    },
    {
      "id": 2,
      "name": "2 заметка",
      "text": "Текст второй",
      "userId": 1
    },
    {
      "id": 3,
      "name": "Третья заметка",
      "text": "Габен сразу создаст 4(",
      "userId": 1
    }
  ]
}
```

2. Запусти json-server:
```bash
cd vue-project
npx json-server db.json --port 3000
```

3. В **другом терминале** запусти проект:
```bash
npm start
```

4. Открой http://localhost:8080

**Что на скрине:**
- Браузер на http://localhost:8080
- Заголовок "Notes app"
- Форма (такая же как в Рисунке 4)
- Внизу **3 карточки заметок** (Bootstrap cards):
  - Карточка 1: заголовок "Первая заметка", текст "Это текст первой заметки"
  - Карточка 2: "Вторая заметка", "Текст второй заметки здесь"
  - Карточка 3: "Третья заметка", "И ещё одна заметка для примера"
- Карточки расположены в 2 колонки (на десктопе)
